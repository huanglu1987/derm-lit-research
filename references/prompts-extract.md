## 3. 从单篇论文提取关键发现、数字与局限

**适用场景：**精读关键试验，准备竞品对比或方案设计的参数来源。

**需要提供：**论文 PDF 或全文文本，必要时附补充材料。

**提示词正文：**

```plaintext
请带着“[我想了解的问题]”阅读附件论文，提取以下内容：
1. 试验设计：分期、随机化与盲法、对照类型（安慰剂/赋形剂/阳性药）、组别与剂量、治疗期与随访期、是否有长期扩展。
2. 受试者：样本量、年龄范围、基线严重程度（如基线 EASI/PASI/SALT 均值、IGA 分布、BSA）、病程、既往系统治疗或生物制剂经历、地区与人种构成。
3. 主要终点：定义、评估时间点、分析人群、缺失数据处理（NRI/MI/观察值）、补救治疗如何计入。
4. 主要结果：各组应答率或变化值的确切数字、与对照的差值及 95% CI 或 P 值、安慰剂/赋形剂组应答率。
5. 关键次要终点：特别是瘙痒 NRS 的起效时间和患者报告结局。
6. 安全性：总体 AE、SAE、因 AE 停药率，以及该机制的特别关注不良事件（例如 JAK 抑制剂的带状疱疹、痤疮、实验室异常、MACE/VTE；外用制剂的用药部位反应）。
7. 作者承认的局限和你认为最大的局限。

每一项标注页码、章节、图或表编号。没有报告的写“所提供文本中未报告”，不要推测。
```

**皮肤科要点：**安慰剂组应答率在皮肤科试验中波动很大，它直接决定差值和样本量假设，务必单独提取。外用药还要提取每日用药次数、最大用药面积和赋形剂组的应答率。

## 4. 把多篇论文整理成并列证据表

**适用场景：**竞品对比表、立项报告附表、Meta 分析数据提取。

**需要提供：**多篇论文或第 3 条的提取结果。

**提示词正文：**

```plaintext
请把 [附件论文或提取笔记] 整理成可粘贴进电子表格的表格，每项试验一行。
列为：试验名/NCT、第一作者与年份、分期、地区、人群与严重程度、样本量、组别与剂量、对照、合并用药规定、主要终点及时间点、缺失数据处理、各组主要终点结果、与对照差值（95% CI）、对照组应答率、关键安全性信号、最大局限、出处位置。

标出可能共享同一数据集或受试者的论文（主文与亚组、汇总分析、长期扩展），提醒我检查是否重复计数。不明确的单元格填“Unclear”。
```

**皮肤科要点：**跨试验比较应答率前，先看终点定义是否一致（IGA 与 vIGA-AD、PASI 75 的时间点、NRI 还是观察值），这张表的价值就在于把这些差异摆在一起。

## 5. 判断哪些研究的证据最强

**适用场景：**决定立项依据、选择样本量参数来源、写综述时给证据分级。

**提示词正文：**


## 6. 弄清两项研究为何结论不同

**适用场景：**两个试验结果不一致、全球与中国数据不一致、或者竞品数据看起来“更好”时。

**需要提供：**两篇论文或其提取结果，具体分歧点。

**提示词正文：**

```plaintext
请就“[具体结论，如：第 16 周 EASI-75 应答率]”比较 [研究 A] 和 [研究 B]。
并列对比：人群与基线严重程度、地区与人种、既往治疗经历、合并用药规定、终点定义与时间点、分析人群与缺失数据处理、对照组应答率、随访时长、结果。
找出最多三条可能解释分歧的差异，每条标注“论文中有记载”或“比较后推断”。
如果两个结果在不同条件下都可能成立，用一句话说明这些条件。
```

**皮肤科要点：**常见的分歧来源包括安慰剂组应答率高低、是否允许合并 TCS、基线严重程度入组门槛、亚洲人群比例以及季节因素。
